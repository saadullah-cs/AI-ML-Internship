# Week 1: Python Data Stack & Preprocessing

## Overview
This week focused on building a strong foundation in the core Python data manipulation stack. The tasks involved ingesting raw data, handling missing values, standardizing formats, and performing initial data wrangling using Pandas and NumPy.

## Key Deliverables
*   Data cleaning and imputation pipelines.
*   Formatting and standardizing tabular data for machine learning ingestion.
*   Exploratory data manipulation using NumPy arrays and Pandas DataFrames.

## Technologies Used
*   Python
*   Pandas
*   NumPy
